# 三模块使用与审核

默认制作工作台同一named iframe切换A/B/D，初始D，三页也可独立打开互通。

| 页面 | 内容 |
| --- | --- |
| A 大纲与关系树 | 主题、关系、冲突、走向与结局 |
| B 角色场景物品生成 | 统一资产、服装版本、纯空间参考和关键物品正文 |
| D 分镜与视频提示词 | 唯一分镜、同版派生九格、引用九格的视频正文 |

按本集增量复用和补缺，执行方自行读取相关上游，链接与稳定名称引用；用户只复制和看真实效果，不重复提交整部原作或行政材料。

复制JSON、展开的只读textarea及实际raw（存在时）逐字一致，每项保留一键复制与展开全文；失败明确提示，不假成功。当前服装版本、场景、物品和共同美术进入实际正文，九格与视频沿同版D，文字准备、生成图片和有效参考的状态分别说明。

嵌入可收起重复页头，独立打开正常。模块消息检查工作iframe.contentWindow、固定类型与A/B/D白名单；不接受任意URL或动作。

监工窗口统一只读审核，执行窗口直接写入与整改；同文件同轮一位实际写手，执行方不再组织另一层质量审查。文字检查包括台词/speaker、服装版本名/具体衣着/素材相属、空间朝向与移动、控制权、九格映射、SEG时长和复制全文。同场连续板核上一认可终态到下一起态，转场与时跳依本场基准和定稿选择起态；实际图另审，不用文本一致宣称效果必然正确。

问题给位置与验收标准，交原写手修后复核；说明本地逻辑、真实交互及媒体观察各自覆盖。快照和少量证据放项目与技能发现目录之外，正常可见，不增加用户必读报告。
