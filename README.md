# su686

su686 是可安装的短剧制作工作流技能，用于原创、改编及已有定稿的分集准备。它把故事、统一资产、分镜、剧情九宫格和视频提示词连接起来，交付互通、可展开全文并一键复制的 HTML。

## 安装

在支持 Codex 技能的环境中，可直接向自带的 skill-installer 提出：

```text
使用 $skill-installer，从 https://github.com/su2517108202-blip/su686
安装仓库根目录的技能，安装名称为 su686。
```

安装参数对应仓库 `su2517108202-blip/su686`、技能路径 `.`、名称 `su686`。安装后在下一轮会话调用。包内只有指南与 UI 元数据，无需安装本仓库的脚本或运行时。实际图片、视频及配音工具由使用环境提供。

## 调用

```text
使用 $su686，为【作品名】准备本集 A/B/D 三模块。
已有定稿：【当前剧本或分镜的位置】。
已有资产：【角色、服装版本、场景和关键物品的位置】。
已选模型、画风、画幅：【本作品选择；未决项再校准】。
本轮范围与停点：【例如只准备本集九宫格与视频提示词】。
```

已有定稿和已经确认的选择直接沿用。每次制作开工先校准真正未决事项：已安装 grill-me 时先调用它；未安装时执行技能内的精简追问，一次一个关键问题，已确定内容不重复询问。grill-me 不是安装硬依赖，开工校准也不是可随意跳过的环节。

## 工作流与交付

| 模块 | 交付内容 |
| --- | --- |
| A 大纲与关系树 | 主题、关系、人物目标、冲突、走向与结局 |
| B 统一资产 | 角色身份、服装版本、可复用场景空间基准、关键物品与生成正文 |
| D 分镜与视频提示词 | 定稿镜头、同版派生的 3×3 剧情九宫格，以及引用认可九格的视频正文 |

三份 HTML 互通，制作工作台可在同一工作区切换 A/B/D，初始 D。每项正文提供展开全文与一键复制，用户复制后按实际工具生成并查看结果；不增加每段手动下载材料的流程。技能执行方负责制作这些页面，本包不附自动渲染器或自动生产脚本。

每集先复用已有资产，再补新人物、剧情换装、新地点及必要物品状态。D 是镜头真源：先确定动作、表演、摄影和切点，再派生九格。九格表达镜头内的关键阶段，不要求九次切镜；视频输出正常连续单画面。

## 连续性与制作选择

- B 按场景维护门窗、家具、通道等少量锚点的相对方向和距离及认可图；摄影换角度、换景别时保持同一物理布局。
- D 写本段起态、动作造成的变化和终态，包含人物位置与朝向、服装版本、关键物品位置和持有者。同场连续段承接上一认可终态，转场或时跳按定稿选择新起态，回旧场景复用原基准。
- 反打可以改变屏幕左右；推拉和跟移不自动移动人物或门窗。复制或提交正文带本段需要的具体锚点、路径、起终态和摄影关系。
- 模型、画风、画幅、资产版式与参考额度按作品及实际渠道选择。SEG 为 5–15 整数秒；段内镜头可短于 5 秒、可用正小数，连续覆盖并合计等于 SEG。
- 定稿台词含标点与说话人逐字保留。正式配音使用独立固定 TTS，模型原音轨整条剔除，再对齐配音和环境声；只有对应说话人在开口时段开口，画外声不带动可见嘴部。
- 两个窗口分工：监工统一质量审核，执行窗口直接制作和整改，可使用助手提速，不组织第二层质量审核。同文件同轮一位实际写手。

## 能力边界

这是工作流指南，规则与文字校验不保证生成模型必然遵守，也不代表已经完成整部作品或所有跨段情形的实图、视频验证。实际人物、空间、动作、台词、嘴窗、摄影及节奏由监工依据真实媒体审核。

需要自动调用时先按授权范围保存实际正文、附件与调用身份。未知结果只回查原调用，不自动重新提交。实图违背布局或终态时保留已认可基准，先定位正文、参考或模型执行中的失败，再按授权做有限验证。
